Off by default. A scanned page — a filed ID card, a signed form — currently contributes nothing to the index; turning this on means whatever is drawn on that page gets read and indexed, verbatim. Runs entirely on this machine, applies to future scans (not retroactively), and only to a PDF page with no text layer at all — a PDF that already has real text is never re-OCR'd.


        
      


      

      
The API key is stored in a 0600 file inside your vault, not in the config file, and is never sent back to this page. Automatic titles and tags use the same provider. The embedding model, vector size, and chunking are not settings: changing them would invalidate everything already indexed, so they stay in the config file.
